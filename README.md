# Java Calculator 🧮

A simple console calculator built with Java.

## 📌 Description

This project is a basic calculator that allows the user to enter two numbers and choose an arithmetic operation.

The calculator performs:

- Addition `+`
- Subtraction `-`
- Multiplication `*`
- Division `/`

It also handles division by zero.

## 🛠 Technologies

- Java
- Scanner
- switch-case
- if-else
- Basic data types
